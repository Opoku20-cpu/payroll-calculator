# payroll-calculator
A console-based C++ application designed to calculate employee basic salary, tax deduction, SSNIT contributions, and net salary.

## Project Overview
This is a console-based  **Payroll Calculator Application** developed in C++ as part of my Computer Science coursework. The program takes an Employee's basic salary input and automatically computes key statutory deductions to determine their final net salary.


## Key Features 
* **user Input Processing:** Accepts the employee's name and basic salary.
* **Tax Calculation:** Automatically computes a 30% income  tax deduction based on the basic salary.
* **SSNIT Contribution Tracking:** Computes a 20% SSNIT deduction from basic salary. 
*  **Net Salary Evaluation:** Accurately subtracts both the tax and SSNIT amounts from the basic salary to calculate the final take-home pay.
* **Console Output Summary:** Displays the calculated tax, SSNIT, and net salary values instantly.

## Core Concepts Demonstrated
* **Variables and Data Types:** Efficient use of 'string'and 'double' to store payroll information.
* **Basic Arithemetic Operators:** Using formulas to calculate percentages and differences.
* ** Standard Input/Output:** Utilizing 'std::cin' and 'std::cout' for seamless terminal interactions.
